# 角色美術提示詞（hand-drawn skill 第 5 號：MS Paint 烂涂鸦）

由 `.claude/skills/hand-drawn/scripts/render_prompt.py --style 5` 產生，未經改寫。
遊戲內的角色是依照同一份配方程序化繪製（`src/art/paint.ts`、`src/art/characterArt.ts`、`src/art/enemyArt.ts`）：
抖動且斷續的線條、比例刻意不對、涂出邊界的大塊純色、像素鋸齒、白色背景（作為紙片外框）、沒有漸層與精修。

## 麻美吉 Mametchi（主角）

```
把麻美吉（Mametchi）：奶油黃色圓滾滾身體、頭頂兩隻深藍色尖耳朵、黑豆眼、粉紅臉頰的拓麻歌子小怪物，全身正面站立画成极其笨拙、潦草、可怜兮兮的烂涂鸦,像是用鼠标在 MS Paint 里一笔一笔硬画出来的。
线条歪扭、抖动、断断续续;比例荒谬地不对,该圆的不圆、该直的不直。
填色是大块粗糙的纯色,明显涂出边界、有像素锯齿、低质量数字感。
整体"明明想画对却处处不对劲",越烂越好笑;纯白背景,构图随意。
不要任何专业感、精修、写实光影、渐变或漂亮细节——刻意地丑、刻意地业余。
```
